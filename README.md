# Shazeb Ashique

Software engineer in Toronto. I brought Canada Life’s e-contract delivery system into production, from the Spring Boot services behind each contract to the Vue interface people use to deliver it. These days my open-source work focuses on how AI agents find and share context.

## What I’m building

- **[AetherBus](https://github.com/ShazebA/aetherbus)** lets agents follow an event stream and fetch the context behind an event through MCP. It supports NATS JetStream and Kafka.
- **[Course Skill Builder](https://github.com/ShazebA/course-to-skill-builder)** turns a course recording into a Claude skill. The local CLI pulls together the transcript, screenshots, and supporting docs.
- **[Memoir](https://memoir-ten-teal.vercel.app)** is a journal for the web and iPhone. You get one page a day. At midnight, the database seals it.
